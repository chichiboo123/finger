# 어린이용 인물 상상 교육 웹앱 「핑거피플」 개발 프롬프트

## 1. 프로젝트 개요

어린이가 손가락을 하나씩 선택해 새로운 인물을 상상하고, 인물의 특징을 글과 그림으로 표현할 수 있는 교육용 웹앱 **「핑거피플」**을 개발해줘.

손가락 하나가 한 명의 인물을 의미한다.
기본 화면에는 한쪽 손의 다섯 손가락이 나타나며, 각 손가락을 클릭하면 해당 손가락을 바탕으로 인물을 만들 수 있다.

사용자는 인물의 이름과 특징을 작성하고, 확대된 손가락 위에 직접 그림을 그릴 수 있다. 완성된 인물은 손 모양 또는 디지털 인물 카드 형태로 정리하고 출력할 수 있어야 한다.

주 사용자는 초등학생이므로 기능이 많더라도 조작 방법은 직관적이고 단순해야 한다.

---

## 2. 핵심 개발 원칙

* 어린이가 설명을 읽지 않아도 쉽게 사용할 수 있는 구조
* 깔끔하고 밝으며 친근한 교육용 디자인
* 지나치게 유아적이거나 장식적인 디자인은 피하기
* PC, 태블릿, 스마트폰에서 모두 사용할 수 있는 반응형 웹앱
* 태블릿과 터치펜을 활용한 드로잉에 최적화
* 별도 로그인 없이 바로 사용 가능
* 작성 중인 내용이 쉽게 사라지지 않도록 자동 저장
* GitHub Pages와 같은 정적 호스팅 환경에서도 핵심 기능이 작동하도록 구성
* 모든 인터랙션에 명확한 시각적 피드백 제공
* KRDS 디자인 원칙과 웹 접근성 기준을 반영

---

## 3. 기본 화면 구성

### 3.1 헤더

다음 요소를 포함해줘.

* 앱 이름: **핑거피플**
* 영문 표기가 필요하면 보조적으로 **Finger People** 사용
* 짧은 설명:
  **손가락에서 시작하는 나만의 인물 상상**
* 도움말 버튼
* 새로 만들기 또는 초기화 버튼

본문용 기본 폰트는 **Pretendard GOV**로 설정해줘.

페이지 타이틀에는 앱의 상상 활동 분위기와 어울리는 별도의 한글 폰트를 사용할 수 있지만, 가독성이 떨어지거나 지나치게 장식적인 폰트는 사용하지 마.

아이콘은 **Google Material Symbols 또는 Google Material Icons**를 사용해줘.

---

### 3.2 메인 손 화면

앱을 처음 실행하면 화면 중앙에 손을 펼친 형태의 일러스트가 나타나야 한다.

기본 상태에서는 한쪽 손의 다섯 손가락만 표시한다.

각 손가락은 서로 독립된 인물 슬롯이다.

손가락 위에는 다음 정보를 간단히 표시할 수 있다.

* 인물 번호
* 인물 이름
* 완성 여부
* 선택 상태

아직 인물을 만들지 않은 손가락에는 `+` 아이콘이나 **인물 만들기** 안내를 표시해줘.

손가락에 마우스를 올리거나 터치하면 해당 손가락이 강조되어야 한다. 선택한 손가락은 테두리, 그림자, 배경색 변화 등을 이용해 명확하게 구분해줘.

손가락의 선택 영역은 어린이가 터치하기 쉽도록 충분히 크게 만들어줘.

---

### 3.3 손가락 확장 기능

기본 한쪽 손의 다섯 인물 외에 더 많은 인물을 만들 수 있도록 **반대손 펼치기** 또는 **10명으로 확장하기** 버튼을 제공해줘.

버튼을 누르면 반대쪽 손이 자연스럽게 등장하며 총 열 개의 손가락을 사용할 수 있어야 한다.

다시 축소할 수 있는 기능도 제공해줘.

확장된 손에 이미 작성된 인물이 있다면 축소할 때 해당 데이터가 삭제되지 않도록 해줘.

---

## 4. 인물 만들기 활동

손가락 하나를 선택하면 해당 손가락이 확대되고, 인물 정보를 작성하는 편집 화면이 열린다.

PC에서는 다음과 같은 2단 구성을 권장한다.

* 왼쪽: 확대된 손가락과 드로잉 영역
* 오른쪽: 인물 정보 입력 영역

태블릿과 스마트폰에서는 드로잉과 정보 입력 영역을 위아래로 배치해줘.

현재 편집 중인 인물이 몇 번째 손가락인지 명확하게 표시해줘.

예시:

* 왼손 엄지 인물
* 1번 인물
* 현재 편집 중

이전 손가락과 다음 손가락으로 이동할 수 있는 버튼도 제공해줘.

---

## 5. 인물 정보 입력 항목

각 인물마다 다음 일곱 가지 정보를 입력할 수 있어야 한다.

1. 이름
2. 외모 특징
3. 좋아하는 것
4. 싫어하는 것
5. 삶의 목표
6. 많이 하는 말
7. 대표 색깔

입력란에는 어린이가 이해하기 쉬운 예시 문구를 넣어줘.

예시:

* 이름: `예: 반짝이`
* 외모 특징: `예: 동그란 안경을 쓰고 머리가 구름처럼 생겼어요.`
* 좋아하는 것: `예: 비 오는 날과 딸기우유`
* 싫어하는 것: `예: 혼자 기다리는 것`
* 삶의 목표: `예: 세상에서 가장 재미있는 놀이터 만들기`
* 많이 하는 말: `예: 한번 해보자!`

긴 내용을 작성할 수 있는 항목은 여러 줄 입력창으로 구성해줘.

각 항목에 글자 수 제한을 적용하되 어린이의 표현을 지나치게 제한하지 않도록 적절한 범위로 설정해줘. 현재 입력한 글자 수도 함께 표시해줘.

필수 입력값은 최소화하고, 이름만 입력해도 인물을 저장할 수 있도록 해줘.

---

## 6. 대표 색깔 선택

대표 색깔은 직접 텍스트로 작성하는 방식이 아니라 시각적 팔레트에서 선택하도록 만들어줘.

### 필수 기능

* 어린이에게 친숙한 기본 색상 팔레트 제공
* 선택한 색깔에 체크 표시
* 선택한 색깔의 이름 표시
* 선택 색상을 인물 카드와 손가락 표시 색상에 반영
* 사용자 지정 색상 선택 기능
* 색상 선택 시 명도 대비를 고려해 글자색 자동 조절

기본 팔레트에는 빨강, 주황, 노랑, 초록, 민트, 파랑, 남색, 보라, 분홍, 갈색, 회색 계열을 균형 있게 포함해줘.

색상만으로 상태를 구분하지 말고 체크 아이콘이나 텍스트를 함께 제공해줘.

---

## 7. 디지털 드로잉 기능

선택한 손가락을 크게 확대하고, 손가락의 외곽선을 캔버스 배경으로 사용해 어린이가 그 위에 인물을 그릴 수 있도록 해줘.

손가락 형태는 인물의 몸통 또는 기본 실루엣으로 활용할 수 있어야 한다.

### 필수 드로잉 도구

* 펜
* 지우개
* 선 굵기 조절
* 색상 선택
* 실행 취소
* 다시 실행
* 전체 지우기
* 그림 초기화
* 확대와 축소
* 캔버스 위치 이동
* 저장 상태 표시

### 구현 원칙

* 마우스, 손가락 터치, 스타일러스 펜 모두 지원
* Pointer Events 기반으로 구현
* 터치 드로잉 중 화면이 움직이지 않도록 처리
* 선이 끊기거나 지나치게 각지지 않도록 부드럽게 표현
* 캔버스 크기가 달라져도 그림 비율이 유지되도록 구현
* 손가락 외곽선은 지워지지 않는 배경 레이어로 분리
* 사용자가 그린 그림은 별도의 투명 레이어로 관리
* 카드 출력 시 손가락 외곽선과 그림이 함께 자연스럽게 표시
* 투명 배경 이미지로도 활용할 수 있도록 구조화

전체 지우기를 누르면 즉시 삭제하지 말고 확인 메시지를 보여줘.

---

## 8. 저장과 상태 관리

각 손가락마다 다음 데이터를 독립적으로 저장해줘.

```text
- 손 구분: 왼손 또는 오른손
- 손가락 위치
- 인물 이름
- 외모 특징
- 좋아하는 것
- 싫어하는 것
- 삶의 목표
- 많이 하는 말
- 대표 색깔
- 드로잉 데이터
- 작성 완료 상태
- 마지막 수정 시간
```

브라우저를 새로고침하거나 창을 닫았다가 다시 열어도 작업 내용을 복원할 수 있도록 **IndexedDB**를 우선 사용해줘.

간단한 설정값은 localStorage를 사용할 수 있다.

다음 상태를 사용자에게 명확히 보여줘.

* 저장 중
* 자동 저장됨
* 저장 오류
* 아직 작성하지 않음
* 작성 중
* 완성

새 프로젝트를 시작하거나 전체 내용을 삭제할 때는 반드시 확인 절차를 제공해줘.

## 9. 인물 카드 화면

메인 화면의 **인물 카드 보기** 버튼을 누르면 사용자가 만든 인물들이 카드 형태로 정리되어 나타나야 한다.

인물 카드는 어린이용 디지털 명함 또는 캐릭터 프로필 카드 형태로 디자인해줘.

### 카드 기본 구성

카드의 왼쪽 또는 상단:

* 사용자가 손가락 위에 그린 인물 그림
* 선택한 대표 색깔을 반영한 배경 또는 포인트 영역

카드의 오른쪽 또는 하단:

* 인물 이름
* 외모 특징
* 좋아하는 것
* 싫어하는 것
* 삶의 목표
* 많이 하는 말
* 대표 색깔

`많이 하는 말`은 말풍선 형태로 강조해도 좋다.

`삶의 목표`는 별이나 깃발 아이콘과 함께 표현할 수 있다.

작성하지 않은 항목은 빈 문장으로 출력하지 말고 자연스럽게 숨겨줘.

---

### 9.1 카드 보기 방식

다음 보기 방식을 제공해줘.

* 전체 카드 보기
* 한 장씩 크게 보기
* 격자 보기
* 작성된 카드만 보기
* 선택한 카드만 보기

카드 수가 많아져도 정돈된 레이아웃을 유지해야 한다.

화면 크기에 따라 자동으로 카드 열 개수가 조절되도록 해줘.

---

### 9.2 카드 선택 기능

각 카드에 선택 체크박스를 제공해줘.

다음 기능이 가능해야 한다.

* 전체 선택
* 전체 해제
* 작성 완료 카드만 선택
* 원하는 카드 개별 선택
* 선택한 카드만 한 번에 출력
* 현재 선택된 카드 수 표시

예시:

```text
3장의 인물 카드가 선택되었습니다.
```

---

### 9.3 개별 카드 기능

각 인물 카드에는 다음 기능을 제공해줘.

* 카드 편집
* 카드 이미지 클립보드 복사
* PNG 이미지 다운로드
* 카드 인쇄
* 카드 삭제

삭제 기능은 눈에 지나치게 강조되지 않도록 보조 메뉴 안에 배치하고, 실행 전 확인 메시지를 제공해줘.

---

## 10. 내보내기 기능

내보내기 화면에서는 다음 두 가지 출력 형태를 선택할 수 있어야 한다.

### 출력 형태 A: 손 모양

* 한쪽 손만 출력
* 양손 전체 출력
* 인물 이름 표시 여부 선택
* 손가락 그림만 출력
* 손가락 그림과 간단한 인물 정보 함께 출력
* 배경 포함 여부 선택

### 출력 형태 B: 인물 카드

* 전체 카드 출력
* 선택한 카드만 출력
* 카드 한 장씩 출력
* 여러 카드를 한 페이지에 배열해 출력
* A4 세로와 A4 가로 레이아웃 선택

---

### 10.1 출력 방법

각 출력 형태에서 다음 네 가지 방법을 제공해줘.

1. 이미지 클립보드 복사
2. 이미지 파일 다운로드
3. PDF 파일 다운로드
4. 링크 공유

### 이미지 내보내기

* PNG 형식 기본
* 충분한 해상도로 저장
* 화면 확대 비율과 관계없이 선명하게 출력
* 불필요한 버튼이나 편집 UI는 결과물에서 제외
* 가능하면 2배 이상의 렌더링 배율 적용

### 클립보드 복사

* Clipboard API 사용
* 지원되지 않는 브라우저에서는 이미지 다운로드 방식 안내
* 성공 시 토스트 메시지 표시

예시:

```text
이미지를 클립보드에 복사했습니다.
```

### PDF 다운로드

* 한글이 깨지지 않도록 처리
* A4 용지 비율 지원
* 페이지가 잘리지 않도록 자동 배치
* 여러 카드 출력 시 페이지를 자동으로 나누기
* 파일명에 프로젝트명과 날짜 포함

예시:

```text
핑거피플_인물카드_2026-07-29.pdf
```

### 링크 공유

공유 기능은 다음 두 단계로 설계해줘.

#### 정적 배포 기본 방식

* Web Share API가 지원되는 기기에서는 완성된 이미지 또는 PDF 파일을 공유
* 지원되지 않으면 공유용 파일 다운로드와 현재 페이지 주소 복사 제공

#### 공유 가능한 프로젝트 링크가 필요한 경우

그림과 인물 정보를 다른 기기에서 그대로 열 수 있는 링크 공유 기능은 별도의 저장소가 필요할 수 있다.

코드를 다음과 같이 분리해줘.

* 기본 앱은 별도 서버 없이 정상 작동
* 공유 저장소 연결을 위한 `shareService` 어댑터 구조 제공
* Firebase 또는 Supabase 같은 저장소를 추후 연결할 수 있도록 모듈화
* 환경 변수가 없으면 링크 공유 기능이 오류를 내지 않고 파일 공유 또는 주소 복사 방식으로 대체
* API 키를 소스 코드에 직접 작성하지 않기
* 공유 링크에는 수정 권한이 없는 읽기 전용 화면 제공
* 공유 데이터의 삭제 기한이나 개인정보 안내를 표시할 수 있도록 구성

단순히 현재 웹앱 주소만 복사하고 이를 완성 작품 공유라고 표현하지 마.

## 11. 도움말과 시작 안내

처음 접속한 사용자에게 짧은 온보딩을 제공해줘.

### 권장 단계

1. 손가락을 선택해요.
2. 인물의 특징을 상상해요.
3. 손가락 위에 인물을 그려요.
4. 인물 카드로 완성해요.
5. 이미지나 PDF로 저장해요.

온보딩은 건너뛸 수 있어야 하며, 이후 도움말 버튼을 눌러 다시 볼 수 있어야 한다.

각 기능에는 긴 설명 대신 짧고 쉬운 안내 문장을 사용해줘.

## 12. 디자인 방향

### 전체 분위기

* 밝고 친근한 교육용 웹앱
* 상상력과 창작 활동이 느껴지는 디자인
* 충분한 여백
* 명확한 정보 구조
* 카드 기반 인터페이스
* 둥근 모서리
* 부드러운 그림자
* 복잡하지 않은 배경
* 어린이의 그림이 가장 돋보이는 화면

### 색상

* 기본 배경은 밝은 중성색
* 주요 버튼은 명확한 포인트 색상 사용
* 지나치게 많은 원색을 동시에 사용하지 않기
* 대표 색깔이 적용된 인물 카드가 서로 구분될 수 있도록 구성
* 텍스트와 배경의 명도 대비 확보
* 오류, 경고, 성공 상태는 색상과 아이콘, 문구를 함께 사용

### 버튼

버튼에는 가능한 한 아이콘과 텍스트를 함께 표시해줘.

예시:

* `edit` 인물 편집
* `draw` 그림 그리기
* `badge` 인물 카드
* `download` 다운로드
* `content_copy` 클립보드 복사
* `picture_as_pdf` PDF
* `share` 공유
* `undo` 실행 취소
* `redo` 다시 실행
* `delete` 삭제
* `help` 도움말

아이콘만 있는 버튼에는 접근 가능한 이름과 툴팁을 반드시 제공해줘.

## 13. KRDS와 접근성 적용

KRDS 가이드라인의 핵심 원칙을 반영해 누구나 쉽게 사용할 수 있도록 개발해줘.

### 필수 적용 사항

* 의미에 맞는 시맨틱 HTML 구조
* 키보드만으로 모든 기능 조작 가능
* 현재 포커스가 명확하게 보이는 포커스 스타일
* 버튼과 입력창의 충분한 크기
* 터치 영역 최소 44×44px 이상
* 입력 항목마다 명확한 label 제공
* placeholder를 label 대신 사용하지 않기
* 오류 발생 시 문제와 해결 방법을 함께 안내
* 색상만으로 선택 상태를 전달하지 않기
* 명도 대비 확보
* 모달창이 열리면 포커스 이동과 포커스 가두기 적용
* 모달창을 닫으면 기존 위치로 포커스 복귀
* 스크린 리더가 상태 변화를 인식할 수 있도록 ARIA live 영역 사용
* `prefers-reduced-motion` 설정 지원
* 애니메이션은 짧고 자연스럽게 적용
* 작은 화면에서도 가로 스크롤이 생기지 않도록 구성

캔버스 드로잉을 사용할 수 없는 사용자도 인물 정보 작성과 대표 색깔 선택만으로 카드를 완성할 수 있어야 한다.

## 19. 오류 처리

```text
그림을 저장하지 못했어요. 잠시 후 다시 시도해 주세요.
```

```text
이 브라우저에서는 이미지 복사를 사용할 수 없어요. 대신 이미지 파일로 저장해 주세요.
```

```text
공유 기능을 사용할 수 없어요. 파일을 먼저 저장한 뒤 공유해 주세요.
```

입력 내용이나 그림이 저장되지 않았을 때 조용히 실패하지 말고 반드시 사용자에게 알려줘.

### 손가락과 인물

* 다섯 손가락이 각각 독립적으로 작동하는가?
* 반대손을 확장해 열 명까지 만들 수 있는가?
* 손을 축소해도 작성 데이터가 유지되는가?
* 손가락을 선택하면 정확한 인물이 열리는가?

### 입력과 저장

* 일곱 가지 인물 정보를 입력할 수 있는가?
* 대표 색깔을 팔레트에서 선택할 수 있는가?
* 새로고침 후에도 내용이 복원되는가?
* 자동 저장 상태가 표시되는가?

### 드로잉

* 마우스, 터치, 스타일러스가 모두 작동하는가?
* 펜, 지우개, 굵기, 색상 변경이 작동하는가?
* 실행 취소와 다시 실행이 안정적으로 작동하는가?
* 그림과 손가락 외곽선이 올바르게 출력되는가?

### 인물 카드

* 작성한 정보와 그림이 카드에 정확히 나타나는가?
* 개별 카드를 복사하고 다운로드할 수 있는가?
* 원하는 카드만 선택할 수 있는가?
* 선택 카드만 묶어서 출력할 수 있는가?

### 내보내기

* 손 모양 이미지가 선명하게 생성되는가?
* 인물 카드 이미지가 잘리지 않는가?
* 한글이 깨지지 않는 PDF가 생성되는가?
* 여러 카드가 페이지에 적절하게 나뉘는가?
* 지원되지 않는 공유 기능에 대체 방법이 제공되는가?

### 접근성

* 키보드만으로 주요 기능을 사용할 수 있는가?
* 포커스 위치가 명확한가?
* 색상 외의 선택 표시가 제공되는가?
* 작은 화면에서도 버튼을 쉽게 누를 수 있는가?
